## L1：文案、批次与内容包历史分页

目标：超过单页上限仍能访问早期记录，切换页不会丢失编辑草稿、审核备注或内容包选择。

允许文件：`apps/web/src/content/ContentStudio.tsx`、`apps/web/src/batch/BatchStudio.tsx`、`apps/web/src/packages/PackageStudio.tsx`、对应三个 `api.ts`（仅分页相关）、`tests/content-ui.test.tsx`、`tests/batch-ui.test.tsx`、`tests/package-ui.test.tsx`。禁止修改图片组件、共享 schema、下载动作、后端、CSS 和文档。

实现：复用现有 offset/limit API，中文上一页/下一页及总数，候选选择器亦可到达老版本；页面与已选版本详情分离，换页不改当前编辑基准；异步回包按商品和请求隔离。不要一次拉取全部历史。生成/创建后可回第一页，但不能隐式放弃脏草稿。内容包跨页保留具体文案和有序图片 ID。

验收：大于页长、翻页失败重试、未保存草稿、跨页选择及切换商品回包隔离的行为测试；定向 UI 测试与 web typecheck。风险：多个列表独立页码、内容包草稿选择的刷新语义。

## L2：图片模板与图片历史

目标：两种本地 1600×1600 卖点图布局，可预览安全区域和文字容纳情况，原图等比不裁切；候选与运行历史分页可达。

允许文件：`src/image/provider.ts`、新增 `src/image/layout.ts`、`apps/web/src/image/ImageStudio.tsx`、`apps/web/src/image/api.ts`（仅分页相关）、`tests/image-provider.test.ts`、`tests/image-ui.test.tsx`。禁止修改 schema、service/repository、迁移、其他组件、共享 CSS、下载函数和文档。

主代理已定义 `ImagePlan.template?: { layout: 'split' | 'stacked'; version: 2 }`。缺字段保留历史布局和旧请求 hash；新 UI 默认显式 v2。新模板固定留白、安全区域和真实原图，标题与卖点按宽度换行并拒绝溢出，不能静默裁去用户文字。错误码 `IMAGE_TEXT_OVERFLOW` 已由主代理登记。可共享纯 TS 版式/换行计算给 UI，不把 sharp 引入浏览器；UI 提供布局选择、比例示意、安全边距和超出提示，产物仍须人工核对。

实现：标题、caption 上限沿用 schema，旧记录显示历史模板；输入/模板变化产生新任务 key 与新候选，未知结果相同输入保持原 key 以便核对。候选和运行记录分别分页，翻页保留所选详情/草稿/审核备注，回包不串商品。原图选择超过一页亦需可访问。不得无限自动翻页查找请求。

验收：长英文/中文、XML 字符、透明图、横竖图、原图哈希与等比例、文字安全区、溢出错误；旧计划和 request 重放兼容；分页及草稿保护 UI 测试、typecheck。测试不能只镜像实现；检查真实 PNG 尺寸和像素边界。风险：字体环境差异，不能声称 Amazon 主图/类目合规。

## L3：停服备份与新目录恢复

执行所有权：受当前代理并发上限约束，本单由主代理实施，再交独立 reviewer 复查；L1、L2 继续由 Luna 独占。

目标：提供不覆盖现存数据的 TypeScript 备份/恢复命令，备份有逐文件大小和 SHA-256 清单，恢复前后检查完整性。

允许文件：新增 `src/storage/backup.ts`、`src/data-cli.ts`、`tests/storage-backup.test.ts`。主代理负责 package scripts、README 和端到端 QA。禁止修改现有数据库/启动代码、schema/迁移、前端、外部服务、其他测试或删除数据。

方案：利用当前 API 固定端口 127.0.0.1:8787，操作期间独占绑定该端口，服务运行时拒绝且新实例无法启动；备份源必须是停服的有效库，拒绝未清空 WAL、符号链接/重解析路径和嵌套源目标，SQLite 只读完整性检查，不迁移不写源库。目的目录必须不存在，备份为 manifest.json 加 data/ 全目录；清单最后写入，未完成目录保留且不可恢复。恢复严格校验清单版本、路径、重复项、文件集合/大小/hash，输出到不存在的新目录，复制后再次校验，禁止覆盖。流式哈希，不全量读取媒体。不能把本工具当成抵御并发恶意本机进程的沙箱。

CLI：`node dist/data-cli.js backup --source <dataDir> --destination <newBackupDir>`；`restore --source <backupDir> --destination <newDataDir>`；错误简明，退出码非零；可选 verify 子命令。工具内部备份格式为私有存储协议，HTTP 公共 schema 不变。端口防护逻辑独立，单元测试 mock 端口或使用注入锁避免影响现有固定端口生命周期测试；主代理另外做真实端口拒绝和恢复检查。

验收：真实 SQLite + 原图/派生图目录在带空格路径备份恢复后字节和ID一致，错误hash/篡改清单/穿越路径/符号链接/已有目标/未停服务/非空WAL都拒绝，不改源库和目标已有文件。定向 tests/typecheck；不接外部模型。风险：大库磁盘容量和本机其他工具并发写入，错误应保留原始库。

## 主代理收尾

真实浏览器操作 JSON/PNG/ZIP 下载，先复现再修下载交互。使用已批准合成 QA 数据验证备份→新目录恢复→再次查看和下载。统一安装/启动/停服命令、更新状态与证据；跨模块类型检查、相关回归、构建和桌面/窄屏浏览器验证后交付。当前任务不自动发布平台内容。

下载复现及所有权补充：正式 JSON 原客户端发送不受支持的 draft=0，主代理改为省略该参数并加真实 client→HTTP 契约回归。内置浏览器临时 Blob 下载超时，原图原生附件链接能返回实际磁盘路径。主代理新增 shared/DownloadLink.tsx，授权 L1/L2 各自把所属组件的 Blob 下载替换为该原生附件链接并更新测试；后端仍在每次下载时验证版本和审核。根代理负责最终浏览器验收。

## 施工结果与验收范围

- L1：文案、运行、批次、包历史与包候选增加分页；加载状态与当前详情分离，跨页保留文案草稿、审核备注、文案 ID 和有序图片。分页失败可重读，异步请求使用 abort/token 隔离。只读取当前页，没有无限加载全部历史。
- L2：新增纯 TypeScript `src/image/layout.ts`，浏览器示意和 sharp 合成共用 v2 布局；两种布局保留原图比例、英文按词换行和 96px 安全区，超出空间拒绝制作。新旧计划不自动互转。图片/运行/原图独立分页；输入指纹约束请求键，已知失败需显式新任务，未知结果保留原键，成功确认后的详情失败直接按已知图片 ID 重读。
- L3：新增 `src/storage/backup.ts`、`src/data-cli.ts` 和备份回归。离线 guard、流式 SHA-256 清单、SQLite 私有副本检查、新目录恢复实现；README 统一使用这些命令。独立 reviewer 对备份未发现 P1/P2，13 项定向用例通过，主代理另外验证真实服务拒绝及含空格路径往返恢复。
- 主代理集成：公共 ImagePlan 可选模板、错误码、原生下载链接与样式、正式 JSON 查询参数修复、旧图片重放/审核持久化回归和架构/交接/状态文档。没有引入依赖、数据库迁移、提供方调用或平台发布行为。

验收修复包括：翻页后最新版本号丢失；新文案残留旧审核备注；同一商品取消再选的旧异步回包；图片终态不能用相同输入明确重试；成功 ack 后详情失败导致丢失原任务；宽英文横向溢出、英文断词和标题顶部越过安全区。相关作者修复后由独立 reviewer 或主代理复核。最终合成图逐像素检查：split 非背景边界 `(96,113)–(1503,1503)`，stacked `(96,112)–(1503,1503)`，均位于 96px 安全区内。

真实浏览器在合成库验证 JSON/PNG/ZIP 磁盘下载、跨页草稿/选择、旧文案/图片/包、失败批次以及两种 v2 生成。37 文件备份恢复保留记录和文件哈希。具体日志、截图、最终检查与未验证项见 [HANDOFF_STUDIO.md](../../HANDOFF_STUDIO.md)。
