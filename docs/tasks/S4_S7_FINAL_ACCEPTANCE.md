## 已发现并修正的集成问题

- 批量路由中间件原本覆盖整个 `/api`，误拦旧研究/文案接口；现在只覆盖批次和导入路径，旧 25 项 HTTP 回归通过。
- 图片文件 ID 与数据库产物 ID 统一；读取使用受控路径、完整解码、大小和哈希复核。
- 批次最后一项已保存、批次终态未提交的重启窗口补齐恢复；不重复调用生成。
- 内容包网络未知结果保留请求和输入，已确认 POST 成功但快照读取失败时复用已创建对象；正式下载异步文件读取后再次检查依据。
- 知识新增请求通过 v7 唯一键映射到原始知识 revision，同键不同输入 409；更新状态、编辑和选择互不静默覆盖。
- 文案和图片审核备注纳入草稿保护；保存文案保持原基准版本，刷新不会偷偷绑定别人的最新稿。
- 图片、批量、内容包集成测试去掉手动 DDL/服务兜底，直接验证正式启动装配。
- 独立收尾审查发现图片中断误记失败、批次恢复丢失已知失败；分别按有界修复单处理。批次恢复先匹配固定输入，再保存原运行 ID 与失败码，未完成项才标记中断。
